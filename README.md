# Дворовый футбол — прототип (Godot 4.5+)

Игрок, напарник, мяч и ворота на асфальтовой «коробке» между панельными домами.

**Запуск:** в Godot 4.5 или новее: Project Manager → Import → выбрать `project.godot` из папки
проекта, затем F5 (главная сцена — `scenes/main.tscn`).

**Обновление после изменений:** в папке проекта выполнить `git pull`.

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Бег (относительно камеры) | WASD | левый стик |
| Ускорение | Shift | RT |
| Удар (держать до 0,8 с — сильнее) | Пробел | B |
| Пас (в напарника, если он впереди) | E | A |
| Вернуть мяч перед игроком | R | Y |

## Где менять параметры

Все параметры — экспортируемые, их видно в инспекторе при выборе узла в `scenes/main.tscn`:

- **Player** и **Teammate** — общие параметры из `scripts/footballer.gd`: скорость бега
  и спринта, разгон, торможение, поворот; контроль мяча у ног (радиус, расстояние до мяча,
  «липкость»); дальность и угол удара, мин./макс. сила, подъём мяча; сила паса.
  У Player ещё время набора удара и сектор автонаведения паса (`scripts/player.gd`),
  у Teammate — куда открываться и пауза перед ответным пасом (`scripts/teammate.gd`).
- **Ball** (`scripts/ball.gd`) — сопротивление качению и воздуху; упругость и трение —
  в `PhysicsMaterial` мяча.
- **Camera** (`scripts/camera_rig.gd`) — смещение/угол, сдвиг вперёд, плавность.
- **Goal** (`scripts/goal.gd`) — размеры ворот.
- **Yard** (`scripts/yard.gd`) — размеры поля и коробки.

## Устройство

- Игроки и мяч физически не сталкиваются: на мяч действуют только `Ball.touch()`
  (ведение, приём) и `Ball.kick()` (удар, пас), поэтому двойного импульса нет.
- Мяч у ног держится через скорость (мяч тянется к точке перед игроком), а не телепортом:
  он по-прежнему физический и отскакивает от препятствий.
- Сила паса рассчитывается по дистанции так, чтобы мяч приходил к адресату со скоростью
  `pass_arrive_speed`.
- Пол — один плоский коллайдер; трещины и разметка рисуются шейдером `shaders/asphalt.gdshader`.
- Гол засчитывается, когда мяч целиком пересекает линию между штангами со стороны поля.
  Повторно — только после возврата мяча на поле или сброса.
- Человек собран из примитивов с процедурной анимацией (`scripts/human_model.gd`) — временно,
  вместо готовой модели.
- Звуки сгенерированы скриптом `tools/make_sounds.py`.
